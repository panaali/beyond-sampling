# T49 conditional ranks and two-input suffix protocol

Scope extension86a43c1 was pushed before this phase. No full accuracy claim; omitted last-reset strata remain explicit.

1. Generic rank conditional: for N iid older inputs, one reset pair and fixed distinct suffix values, compute the joint mass of E and a requested label being second largest. Suffix label: evaluate the appropriate coefficient0 or1 of the old-prefix/pair count PGF at its value. Old iid label: integrate a marked value t with N−1 remaining old inputs and pair PGF. Reset-pair label: integrate its marked t, restricting the other pair variable to the wedge endpoint, and combine its above/below-t masses with a binomial old count. All integrations split at suffix values and0. Reject fixed suffix ties rather than silently select a target tie convention; network output ties retain first-index ownership.

Falsifiers: complete sum over all labels must equal r for small N and fixed suffixes, all old-label masses must agree, and suffix-label values must agree with independently enumerated Bernoulli count coefficients. Compare the two terminal formulas already independently checked; zero/infinite slope require explicit branches. Numerical adaptive errors remain estimates.

2. Exact two-input suffix partition: first input v>0; write second input z*v with z>−kappa, exactly the no-further-certificate region. Hidden output is v*ReLU(Wh*Wi+Wi*z). Build all gate roots and all pairwise readout roots with Fraction arithmetic, restrict to z>−kappa, include z0 and1 for input-rank ordering, and assign first-index labels on open pieces. Merge adjacent pieces only when gate/prediction/rank data agree. Check exact rational interiors against direct recurrence and reject any non-suffix prediction in the initial bounded integral rather than change labels.

3. If all selected labels are suffix labels with positive selected input, compute their pair-rank masses by the analytic Owen-T identity G0(t)=.5*Phi(t)+T(t,kappa)−q and G1(t)=.5*Phi(−t)−T(t,kappa), q=atan(kappa)/(2pi). Independently compare to positive scalar rank integrals before use; cancellation in extreme tails remains qualified, reject materially negative values. No fitted mass correction.

4. Base-only partial integral: in each exact angle interval theta=atan(z), v=r*cos(theta), second=r*sin(theta). Two-Gaussian density is exp(−s)ds*dtheta/(2pi), s=r²/2. Fixed angular Legendre and radial Laguerre orders8,16,32; refinement is a convergence diagnostic, not an error certificate. Each node uses only the rank law and piece label, no model forward. Count all nodes/special functions/setup CPU and retain values at every order. Independent fixed Cartesian-ratio quadrature or adaptive radial checks only if the refinements disagree materially. Initial cycle<=20CPU, one thread/2GB. Never call remaining omitted mass zero accuracy or claim a small-model solution.
