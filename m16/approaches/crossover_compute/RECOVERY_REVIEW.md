# Recovery and scope review

## Question
Which saved work was missing from the shared branch, and can work resume without losing or repeating completed experiments?

## Method
The live roster contained only root. Six successor workers inspected their own clean or interrupted worktrees and identified incomplete phases. Root recovered394 ordered research/review commits across six lanes, verified changes remained in approach folders, and compared every recovered folder against its exact worker checkpoint. All six snapshots matched before publication. Full commit/folder manifest is RECOVERY_MANIFEST.json.

## Status
Preservation complete and pushed. Six workers active again. Root is reviewing scope and integrating the next bounded phases. A live status check is a point-in-time observation, not a persistent execution guarantee. Saved ownership alone does not demonstrate running work.

All prior variants, failures, local fixes, costs and independent-review records are retained. Registry rows now distinguish computational preservation from scientific validation. ## Compute accounting
Recovery uses git/text/source comparisons only; no completed model experiment was rerun. Scientific checks remain separately accounted in each author/reviewer folder. New work retains the shared primary110CPU/review20CPU bounded locks, one numerical thread and2GB/process limits.

## Claims
[measured] Six recovered folder snapshots match worker checkpoints. [inferred] These records allow work to resume without repeating completed experiments. No independent full scientific rerun or new confirmed claim is asserted by preservation alone.

## Alternatives not ruled out
Unmerged later checkpoints and interrupted untracked work may need additional review. Validity is not established by a clean git diff. Untested representations, better integration and lower-cost mechanisms remain open where explicitly documented.

## Failure modes
Ending a management turn can leave completed workers without active supervision. A task board can accumulate stale active rows while workers advance. The correction is a live-roster check, prompt checkpoint integration, removal of completed claims, and independent review before moving scientific conclusions forward—not an unsupported promise of indefinite background activity.
