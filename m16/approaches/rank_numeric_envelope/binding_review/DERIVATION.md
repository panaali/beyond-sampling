# Finite no-rescale inference and its provenance condition

The pinned installed DLARFG compares N with 1 at `d3e8d9`. For every N>1, control reaches the initial DNRM2 call at `d3e8ff` before testing the returned norm. The only other DNRM2 call is `d3eb01`, after the rescale loop. Both call the same PLT entry `86030`, with one `R_X86_64_JUMP_SLOT` for the symbol. No alternate inlined norm path appears in this function. This is direct installed-binary evidence, in addition to the previously reviewed public source.

The new 12 frozen direct-versus-observed controls reproduce every output bit. They record one reflector each; N<=1 records no norms, ordinary N>1 records one, and the two subnormal N>1 cases record two. Dynamic loader output identifies OpenBLAS's DNRM2 and DLARFG symbol bindings to the observer. Additional library-to-library lines are the observer's explicit handle-based lookup of the real functions; they are not evidence that the PLT bypassed the observer. The test exercises the extra-norm path rather than inferring coverage only from ordinary inputs.

The saved runner resets the census before cold setup, reports it, then resets before the geometry phase. Its reset does not occur inside either measured phase. Reports assert no row-cap overflow. Every stored phase has positive counts and zero failure/overflow flags. Independently contracting all 16 runs × 2 phases gives exact equality between DNRM2 calls and N>1 DLARFG calls in each phase, not merely after aggregation. The cold phase is included only once when modes are composed.

Under the recorded observer configuration, every active reflector contributes at least one observed norm; every rescale contributes one extra; other callers contribute nonnegative counts. Equality therefore forces zero rescale events and zero extra callers in these finite phases. It does not establish a generic runtime property. It also does not justify subtracting AST geometry norm costs by operation name: NumPy can implement those through dot/sqrt rather than DNRM2.

Historical provenance is a condition: the saved execution must have used the reviewed observer and loader arrangement. The new binding trace verifies the pinned current configuration; it is not a recovered historical trace. Retain the generic 113-unit envelope if that provenance condition is not accepted. The finite conditional envelope is 10 reflector-exclusive named units (5 arithmetic, one negation, one SIGN, one absolute value, two comparisons), with child work still separate. Neither is a complete native-cost result or a hardware instruction count. Counter-width, integer/control, memory and runtime qualifications remain.
