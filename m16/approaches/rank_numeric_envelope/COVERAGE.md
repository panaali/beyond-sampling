This does not mean complete cold setup: the larger Legendre eigensolver and other model-free setup remain outside this ledger. The source proof prices arithmetic, comparisons, negation and named elementary functions as stated in each derivation. SIMD inactive lanes, compiler transformations, casts, integer/index work, character dispatch, memory and runtime are not uniformly included. Separate executed-lane cost audits must not silently add this ledger or treat its source bounds as the same convention.

Controls could detect ABI/source-semantic defects, and preserved corrections include the lastN-versus-max error, unprefixed symbols, and right matrix-scan orientation. Finite native parity does not prove every floating path follows source arithmetic counts. Historical binding and complete observation remain premises; current binding is not proof of past binding.
