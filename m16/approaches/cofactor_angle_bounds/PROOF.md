# Numerator-only theorem

Let l<=p<=h be rational and x>0. For f(y)=atan2(y,x), f'(y)=x/(x²+y²)>0. If d is the distance from0 to[l,h], its maximum derivative there is M=x/(x²+d²). The mean-value theorem gives |f(y)−f(p)|<=M max(p−l,h−p) for all y in the interval. All quantities in that bound are exact rational numbers. Every f(y) lies in(−pi/2,pi/2), so replacing any larger bound by4 remains valid because pi<4.

When d>0, M<=1/(2d) follows from(x−d)²>=0. Record that independent denominator-uniform comparator; it is not a second selected estimator. For x=0 and an interval strictly positive or strictly negative, the angle is respectively pi/2 or−pi/2, so error0. If the interval contains0, an exact numerator0 would make the real angle undefined. Return unknown, not a false certificate based on the programming language's atan2 zero convention. Negative or nonfinite x is outside this theorem.

The theorem treats x and all interval/point values as exact stored binary values. It does not control how x was computed, covariance or principal determinant errors, libm evaluation, quadrature truncation, or the source's other terms. The existing cofactor enclosure theorem supplies the exact stored-minor numerator containment separately.
