# T25 explicit executable-description audit review

Fixed3-bit type tags, Elias-gamma lengths/integers, binary64 floats and
fixed-schema AST nodes yield an unambiguous prefix code relative to the
recorded Python AST/NumPy environment. Complete standalone objects must
be uniformly framed: (AST,args), with args=None for original predictors.
The repaired framing adds9 bits to originals and6 to library-plus-payload
concatenation. The earlier unframed totals remain preserved.

Independent check_description_code_review.py computes recursive code
lengths without using the author's codec. Original M16 has78 fitted floats
(15 five-parameter neurons and one three-parameter neuron),36182 standalone
bits; M32 has142 P-table floats,64942 bits. It verifies all40 conditional
dictionary header/matrix lengths and standalone framing equations. Fixed
float literals outside the declared fitted regions remain structural code.

Subset counts are syntactic occurrences/distinct subset literals, not a
complete estimate of search complexity. Position selectors and functional
choices remain charged in the executable AST. Nine-bit-mask diagnostics
must not be added again to the AST total. Binary64 precision, identifier
spellings and retained reporting-name construction are declared encoding
choices; they can dominate differences and admit shorter alternative codes.

These are decodable upper bounds relative to a shared decoder/library,
not lower bounds on intrinsic complexity, minimal-description-length
solutions or human legibility scores. Standalone and conditional costs
must only be compared on the same basis. Training-only QR machinery is
properly excluded when deployed coefficients are returned to the original
feature basis; its training/search compute is a separate accounting issue.
