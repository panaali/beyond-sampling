# Independent density oracle, reconstruction and jump review

Read density_shape.py, affine_volume.py, quadrature_volume.py and the exact
two_input.Law representation in the T58/T77/T83 owner's worktree. This memo
does not implement a competing transport engine.

## Bounded two-input oracle

For each first-input sign, use source coordinates(s=|x1|,x2), with s>0 and
both absolute inputs<=L. On an area gate cell h=B(s,x2), the density is
phi(s)phi(x2)/|detB|, restricted to the mapped sector and input box. For a
rank-one axis cell, write its nonzero row a, sigma=||a||, e=(-a1,a0)/sigma.
Conditioning on output coordinate z gives source mean a*z/sigma² and residual
coordinate t~N(0,1). Every source inequality n·source>=b becomes
(n·e)t>=b-n·mean. Thus the code's lower/upper residual clipping and density
phi(z/sigma)/sigma * [Phi(upper)-Phi(lower)] have the correct coarea factor.
A zero coefficient with an impossible residual inequality makes the interval
empty; subsequent max/min bounds cannot reopen it. Input signs have equal
Gaussian density in s and are summed as separate source sectors.

Source reweighting uses each cell's existing mass, times positive density
values, normalized within the cell. It does not replace the mass itself with
oracle truth. A zero sampled density retains the old weights and records an
unresolved-cell event. Thus the strong one-stage improvement identifies lost
within-cell shape, conditioned on the valid density oracle and existing
quadrature. It is NOT a scalable history-free exact density solver.

## Positive affine reconstruction

A polygon centroid is computed by area-weighted triangle centroids. The
reconstructed density is rho_bar+g·(h-centroid) in normalized cell coordinates.
Its exact cell integral is the existing mass. A linear function has its
minimum at a vertex, so scaling g until every vertex value is nonnegative
preserves positivity throughout the convex polygon. The axis-bin version has
the same midpoint normalization and endpoint positivity. Positive source
quadrature preserves these properties; the final per-cell normalization
corrects numerical weight drift, not an intended change of mass.

Neighbor least squares in widths-normalized coordinates is covariant under
positive diagonal rescaling. Constant/affine fields are appropriate exact
controls, provided neighbor centroids span the fitting dimension and the
limiter is inactive. Rank-deficient fits return zero slope explicitly.
Zero-mass cells are not filled. The current least-squares call is an opaque
numerical kernel whose work counter is not a portable scalar operation count;
no such cost certification is inferred here. Limiter and rank decisions remain
floating, and thin cells/zero neighbors are useful adversarial controls.

## A real internal density jump

Let an old line stratum be h_old=r d, r>0, with density g_d(r) with respect to r.
For a fresh scalar x and BOTH new gates active,

    h = r Wd + x w,
    f_d(h)=g_d(r(h))*phi(x(h))/|det(Wd,w)|,  r(h)>0.

Take a point h=s w with s>0 inside the input cutoff and let
n=(-w2,w1). If det(Wd,w) is nonzero and g_d has a finite right limit at0, the
contribution approaches g_d(0+)*phi(s)/|det(Wd,w)| from the side with
sign(n·h)=sign(n·Wd), and zero from the opposite side. Consequently

    f_plus(sw)-f_minus(sw)
       = phi(s) sum_d sign(n·Wd) g_d(0+)/|det(Wd,w)|,

provided the transported AREA contribution is continuous there. The sum must
include both axes and the old input ray d=w; individual jumps can cancel.
For the bounded two-input law here, area pieces are bounded Gaussian densities
on finitely many polygons, W is invertible, and none of their through-origin
boundary rays maps parallel to w. Dominated convergence along the scalar
convolution therefore makes this area contribution continuous at the tested
interior ray point. The fresh origin contribution is a separate singular ray
measure, not part of either area-density limit.

`check_jump_review.py` computes line-density limits directly from exact
Fraction sector inequalities and the finite source boxL6. At z→0+, homogeneous
constraints with zero residual coefficient must still check n·a>=0; simply
substituting z=0 would miss this one-sided feasibility requirement. Nonzero
coefficients give half-lines through0; box constraints give finite endpoints.
For strictly positive w and the nondegenerate trained model, the old ray
is regenerated by x1<0 and x2>0, so g_ray(0+)=(Phi6-.5)phi(0).
