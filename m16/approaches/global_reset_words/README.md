# T50: exact global reset words for mixed-sign H2

## Question
Does the public H2T10 model have open sets of four-input words that reset every initial nonnegative hidden state, improving on the known five-positive-input sufficient event? Claim published and rechecked bb4cff09. The prior T50 owner confirms this fixed-word global-image classification was not attempted; T49 separately owns the same-sign two-input reset wedge.

## Method
Represent arbitrary initial hidden state through homogeneous coordinates y=(s,h01,h02)>=0, sum(y)=1. Physical finite states have s>0 and hidden h0=(h01/s,h02/s); the word becomes s*x. Start affine hidden map B=[[0,1,0],[0,0,1]]. Propagate exact Fraction gate polygons and affine maps in this compact triangle. Retain s=0 recession vertices; discard only exact zero-area cells. Continuity recovers their boundary values from adjacent full cells. Global reset holds iff final B*v=0 for every vertex of every full cell. This certifies unbounded initial states, not just a large sampled box.

For robust reset, retain last preactivation L on each cell. Each finite vertex gives −L_i(v)/s(v); recession vertices must satisfy L_i(v)<=0. Their minimum eta_i certifies L_i(y)<=−eta_i*s(y) globally. The last preactivation changes by at most s*epsilon*C_i under any word perturbation of infinity norm epsilon, where C=sum_(r=0..length−1)|Wh|^r |Wi|. Strict positive eta gives an open reset box epsilon<min eta_i/C_i without assuming gates stay fixed. Failure of this sufficient margin certificate is not proof that no open reset set exists.

### Stronger algebraic discriminator, frozen before its validation
Let Wi=(-alpha,beta), Wh=[[a,-b],[c,-d]], alpha,beta,b,c,d>0, a>d and bc>ad (all true for the public T10 checkpoint). For any fixed inputs x1,x2 and any r>=0, choose first hidden state (u,v), with u=(r−beta*x2+d*v)/c. For sufficiently large v, second preactivation1 is (ad/c−b)*v+a*(r−beta*x2)/c−alpha*x2<0, while second preactivation2 is r. The inverse first-step initial state has v coefficients (b−d²/c)/(bc−ad)>0 and (a−d)/(bc−ad)>0; thus sufficiently large v makes both initial coordinates nonnegative and u,v positive. Therefore the reachable hidden image after ANY two inputs contains the entire second axis.

For any third input x3 choose r>max(0,−alpha*x3/b,beta*x3/d); this forces both third preactivations negative. Hence some finite initial state reaches origin after any three-input word. Any fourth nonzero input gives ReLU(Wi*x4)!=0, so no such four-word is a global reset. Four-word reset events are contained in x4=0 and have zero Gaussian probability. Together with the certified open five-word box this would prove minimal positive-probability global reset length5, under these inequalities. Shorter positive-probability words would yield a forbidden four-word by prepending zeros. This concerns arbitrary initial h>=0; it does not rule out shorter resets from restricted reachable states, adaptive state-dependent events, or useful nonzero coalescence.

Next validation will implement the constructive rational witness directly from these inequalities, separately from polygon enumeration. Test all32 frozen words plus fixed extreme-scale/mixed-sign words, zero-last exclusion, and a fresh rational toy satisfying the assumptions. Independently check exact recurrence and send proof/source to T55. No broader word search is needed if the construction passes; preserve the earlier finite negative unchanged.

Constructive validation (`python m16/approaches/global_reset_words/check_obstruction.py`) passes74 exact rational witnesses in.00849CPU, using the trained weights and a fresh rational toy, with296 exact recurrent steps. Four zero-last exclusions and two parameter-regime rejections pass. `obstruction.py` directly solves the inverse two-step construction and does not use polygon enumeration. Every tested initial state reaches the requested second-axis value, then origin at step3, and a nonzero state at step4. The proof quantifies over all real words with nonzero last input; the74 examples validate its implementation, not its universality.

The upper bound length5 also has the prior independent T50 algebraic proof. For x1>0, c*h1<=a*h2 since c*z1−a*z2=(ad−bc)*old_h2−(c*alpha+a*beta)*x1<0 whenever h1 is active. With a²<bc, x2>0 then forces h1=0. Third positive x3 leaves h2 in[0,beta*x3]; fourth positive x4>d*x3 makes h2>=beta*(x4−d*x3)>0; fifth positive x5<d*(x4−d*x3) forces both coordinates to0. Thus the open event x1,...,x5>0 and x4>d*x3+x5/d resets globally. The checkpoint satisfies every inequality exactly; the fixed word(1,1,1,1,1/20) lies in this event. This is reused from the prior small_h2_910 theorem, not claimed as a new discovery.

## Alternatives not ruled out

## Failure modes

General model-state transport, target-rank augmentation and probability of overlapping word events are out of this initial phase.
