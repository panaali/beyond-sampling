# Published source and evidence inventory

The manifest pins a shared Git snapshot and ten text/source payloads. `T241_DIRECTIVE.md` is copied verbatim from that snapshot's TASKS row. `AUTHOR_TREE.txt` is the exact `git ls-tree -r <snapshot> m16/approaches/neuron_account` result: empty. This is not an inventory of private branches, unpublished work or the entire historical repository.

The current common.py obtains the example model at import, converts weights to binary64, uses h_0=0, returns all T+1 hidden states and applies ReLU after each scalar input. Its target uses NumPy argsort and the readout uses first-index argmax. Source was read only; importing common.py would make a checkpoint/model operation outside this scope.

The current modes.py selects STEADY=[0,1,2,3,6,7,8,10,11,12,13,14,15], calls eig on that principal recurrent submatrix, orders by eigenvalue magnitude and returns V and its inverse. Coordinates are h[:,STEADY] @ Vinv.T. It contains no intervention/replacement execution protocol. The original narrative itself records that the gate set covers only a subset of states and withdraws the unqualified n3/n13 attribution based on nonorthogonal modes. These observations motivate the mode-coordinate contract; no eigendecomposition was recomputed.

state.py computes the head-top-two positions/magnitudes and final-input case. separable.py constructs a feature design and calls least squares on a supplied mask, but does not itself enforce a heldout split or describe an intervention. This observation does not establish historical leakage. FINDINGS.md contains prior group-level terminal mean-ablation claims and explicitly excludes n2,n5,n9; it is a narrative source, not new raw validation of those values.

The independently reviewed T201 fullfit report (`908f2a56`) separates approximately98% task accuracy from approximately95.3% original-network agreement on the frozen original checkpoint. Its exact-state limit (`dd64fb85`, reusing T138 review `8f90409`) is pointwise non-sufficiency for one summary, not a useful probability floor. The residual diagnostic (`aba9dd68`) preserves all five label transitions and sixteen algebraic terms, without causal intervention. T224 projection (`6948ad9f`) is a post-original-result reused-data comparison: hidden error and agreement improve slightly while task accuracy falls. Their text reports are reused with these qualifications; no arrays, scores or confidence intervals were recomputed here.

The T224 theorem is a useful logical control: reducing distance to a nonnegative hidden target need not improve readout classification. It does not prove that any specific T241 intervention will fail or succeed. No past result establishes the new per-neuron causal map, heldout replacement targets, or an architecture-wide capacity claim.
