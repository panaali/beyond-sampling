# Acceptance contract for existing T192 T5 exports

This is a source-derived prerequisite, not an executed data validator or a request to redo geometry. Supply existing files and existing run metadata first; preserve any missing fields as unknown. Numerical T193 work needs its own frozen panel, resource budget and independent source gate after data are available.

1. **Data identity.** For each seed0/2, provide the actual NPZ, byte length and SHA256, creator commit/run identifier and captured completion log. Load only without pickles. Required existing fields: rays(K,5,5), absdet(K), mass_estT(K), mass_ref(K), scalar stride and total. All numeric arrays must have explicit dtype/endianness and finite entries; the masses may be negative, zero or otherwise diagnostic failures and must not be clipped or discarded. Nonfinite rows stop or remain explicitly unresolved. K>0, total>0 and positive integer stride; K must equal ceil(total/stride). No mass-equality assertion is imposed at this provenance stage.
2. **Representation.** Preserve ROW generators and raw binary entries. Record row norm residuals as diagnostics, not a renormalization instruction. Saved absdet is a floating annotation to independently check later, not an exact determinant certificate. A new exact-Gram/rank/determinant preparation, if needed, must be charged and gated separately.
3. **Model and source.** Bind seed,H,T, checkpoint SHA256 or exact Wi/Wh/Wo byte hashes with shapes8,8x8,5x8; identify alg_zoo/library versions and original source commit plus resolved module paths/hashes. Bind fast/pure geometry, exact mode, halves start, TOL and any shared-source patches. Ancillary import dependencies should be disclosed separately from model weights. Original author ancestry currently is not shared; owned snapshot parity does not erase that gap.
4. **Selection.** Bind positive stride, total dimension5 error-simplices and source emission order. Global selected indices j*stride are reconstructible; per-half index/offset and counts, if already available, permit stronger provenance checks. Distinguish sampled error simplices from full leaves and from truth-start captures. No Gaussian mass weight or random-sampling guarantee follows from deterministic stride selection.
5. **Rules and environment.** Record initial T192_RULES5 and T192_SLIVER, T192_FAST, actual DEV, rule-array hashes and thresholds for BOTH arms, NumPy/Torch/Numba/BLAS versions, command and resource logs. For baseline per-parent semantics require initial SLIVER=None or independently verified evidence that no aggregate redistribution occurred; do not simply assume the variable was unset. If inherited splitting affected multiple thin rows, retain those original outputs as aggregate diagnostics and refer correction to DRI.
6. **Reference qualification.** Label mass_ref as same-source refined diagnostic. Record splitting cap/max-depth/termination data if captured, but do not invent them. A missing convergence flag is not a certificate of pairwise threshold attainment. Neither reference column establishes source floating error or geometry correctness.
7. **Review boundary.** Freeze array/schema/provenance findings before selecting any new numerical pilot. All selected failures and unknowns remain; no data-dependent selection of favorable rays. T193 stays blocked until actual arrays exist, and any incomplete provenance must be explicitly accepted or scoped by DRI before interpreting model-level findings.

The immediate deliverable requested of the capture owner is the existing H8T5_zoo0.npz and H8T5_zoo2.npz with the available run/weight/environment sidecar. This document does not require unavailable metadata to be reconstructed by rerunning a whole model.
