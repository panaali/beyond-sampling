# Scoped findings and alternatives

This audit does not declare a method dead. Its finite certificate counterexample
rejects universal outward validity of the pinned cap implementation, under its
actual NumPy ray normalization. The ideal cap containment theorem survives.

| Question | Tried here | Not tried / why |
|---|---|---|
| Does the source cap behave normally on simple cones? | Two orthants, analytic expected caps, independent saved review | No dimension sweep; these are fixed controls, not comprehensive validation |
| Is its floating output always an upper bound? | One exact positive narrow-cone fixture returns zero below a strict exact lower | No trained frequency/error estimate; not needed to refute universal certification and not authorized as a trained replay |
| Does it handle an undefined centroid axis safely? | Four unit cardinal rays, zero axis, finite zero with warning | No assertion this occurs in pointed ordering chambers |
| Can the cap idea be repaired? | Exact theorem and prerequisites reviewed | Outward interval/norm bounds, explicit conservative fallback and alternate axes remain open; implementation would need its own claim/control gate |
| Do saved attribution numbers reproduce? | Independent scalar-loop/fsum checks of every analysis object and selected report rows | No author attribution/evaluator replay; raw arrays have no checkpoint hash/run-source identity, no T5 split archive |
| Does a low-rank input uniquely cause a split? | Contrast, fractional and gradient statistics retained | No unique causal interpretation established; ray means are representation dependent |
| Does removing a split reproduce the fixed-piece effect? | Source examines downstream intervention on existing refined pieces | No adaptive split-removed replay or representation-invariance proof; such work belongs to a separate experiment |
| Does the guard log establish new cell counts? | Saved candidate-point ratios contracted | No repaired traversal; counts of violation events do not determine resulting split/cell counts |
| Does pruning beat sampling with a certified guarantee? | Existing point-reference/historical-cost tables contracted | Retained recipe error, numerical mass/geometry, true full cost and reference error remain unproved; no threshold selection or new performance claim |

The most promising direct numerical rescue for the finite cap defect is an
outward cosine enclosure with a safe fallback when axis/norm/rounding control
is unavailable. It has not been implemented here. Independent reviewers have
checked the exact narrow-cone proof and the stored rays, rather than declaring
all pruning variants exhausted. Claude retains scientific classification.
