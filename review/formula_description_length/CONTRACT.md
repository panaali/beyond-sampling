# A comparable, decodable formula-length protocol

This is a written proposal and prerequisite inventory, not permission to fit or evaluate. A separate published source/control/resource gate is required for every numerical phase.

## Primary object and conditioning

The primary object is an input-to-final-hidden predictor for the same frozen M16,T10 model, followed by first-index readout. H-A1 labels and T241 selected t10 formulas share this target. Report hidden error/R2, original-network agreement and task accuracy separately; do not equate them. A direct-logit predictor and a full160-neuron-step account are separate rows/targets, not shorter encodings of the same required output.

Freeze the exact reference checkpoint/runtime/input dtype and state/readout convention. Report two code totals:
- Conditional final-hidden code, with one explicitly declared common original readout as side information for all methods.
- Standalone label predictor, which includes every required weight/constant not in the fixed universal decoder, including that readout and any retained recurrence.
The original recurrent network should be included as a separately declared representation baseline when a full bits-versus-agreement experiment is authorized. Conditioning on all original weights would trivialize a model-specific description and is not the primary convention. No conditional total may be compared to a standalone total on the other side.

## Concrete finite code, without a minimality claim

Use the reviewed T25 prefix grammar and its single framed tuple(AST, payload), with the exact AST class/codebook and numeric/library semantics pinned. The generic inference-only feature/routing/table/predictor wrapper is included once in AST. Exclude fitting, scoring and prose; include executable family operators, clock constants, absence rules, shared comparator features, numerical casts, output mapping and fallback. Future extraction of an inference-only wrapper must have independent source and roundtrip/parity controls; this phase does not implement it.

The payload has a fixed versioned schema: target tag and dimensions; selected (step, output, family) bindings; a table directory ordered by family/step/output selection; sorted actual cell IDs; coefficient columns and pooled fallbacks in canonical row-major order; required hinge-bank dependency directory; optional readout/recurrence payload according to the declared conditioning. Duplicate output columns and truly identical shared tables may be shared only under an explicit exact identity/reference rule. No favorable deduplication is assumed. Unused training counts/ridge parameters are excluded from the unchanged inference payload but retained in research provenance; if a later compressed predictor uses them, they enter that predictor's code.

For the primary unquantized representation, coefficients are encoded as exact finite binary64 floats using T25's float tag+64-bit payload, not merely64 times parameter count. Shape/length tags, IDs, selectors and framing are charged. Actual intermediate float32 casts remain in the program. If learned arrays turn out to have another dtype, conversion and original bytes must be explicitly bound; no silent precision change. Invalid/nonfinite coefficients stop the phase. This gives a code-dependent upper length for an actual decoder, not minimal Kolmogorov complexity, human understanding or information-theoretic capacity.

A future streaming bit counter/hash may avoid materializing huge strings, but must independently match the original codec on small controls and completely decode a bounded artifact before any large count is accepted. Do not infer arithmetic cost or cache size from bit count; report decoding and inference work separately.

## Evidence gate before a rate-versus-agreement curve

First ask for existing coefficient artifacts, without assuming they exist. Required contents: exact model/runtime/source binding; full selected IDs/coefficients/fallbacks; selected-family mapping; reachable hinge tables; cast policy; dimension and cell-count metadata. Check a source-identical prediction fixture against any retained original predictions before introducing pruning. If artifacts are absent, a separately authorized reproduction must capture them durably during the same fit, ideally coordinated with T258 rather than repeating training. It is new reproduction evidence, not historical byte recovery.

Freeze all candidates before new evaluation. A narrow first compression family could retain a prescribed fraction of final-table cells ordered by TRAINING count (ties by cell ID), use the existing pooled fallback elsewhere, keep all needed hinge-bank tables fixed, and report every fraction separately. Suggested fixed fractions are0,1/16,1/8,1/4,1/2,1 using floor(fraction*C); this is a proposal, not yet an execution scope. The full bank cost is retained even when it dominates. The zero-retention arm may remove an empty ID/table encoding under an explicitly supported decoder, not by silently changing the metric. No post-evaluation threshold choice or best-only reporting.

Before that family is executed, fix the exact treatment of shared columns, unused tables and fraction rounding, then exercise unseen cells, all-pooled dispatch, signed zeros, casts, empty payloads and roundtrip/parity on synthetic controls. Training counts used only to choose retained cells are selection provenance, not inference inputs once the selected IDs are serialized. Other alternatives—bank pruning, cell merging, coefficient quantization, symbolic sharing—remain separate frozen families, not unreported rescues chosen from the test set.

A fresh common evaluation stream must be independent of all fit/validation/previous outcome selection. Predeclare model(s), sample size, seed(s), all candidates and confidence construction based on resource/probability precision, not observed agreement. Preserve per-input target/reference/candidate labels, hidden outputs as needed, exact paired transitions and integer denominators. Account for reuse/dependence across candidates and multiple reported budgets; training/validation selection stays outside final test. This is an interpretability/reconstruction experiment, not a deductive accuracy estimator or an ARC rung pass. Noise/generalization claims need their own panels.

## Decision limits and alternatives

If a table family is much longer than H-A1 at higher agreement, that is an empirical description/faithfulness tradeoff under this code. It does not prove that high agreement requires those bits or that no compact semantic formula exists. If a source-preserving code makes a hand formula longer than a table, names/macros/grammar may explain the order. Always expose payload, routing/structure and shared-program contributions separately.

Failure to recover coefficients is a provenance blocker, not scientific failure. Failure of a fixed pruning family is scoped to that representation, fallback and feature selection. The cheapest discriminators are actual artifact recovery, decoder parity and heldout paired evaluation; unbounded searches, new training or a fabricated rate curve are not substitutes.
